# Goose Duck Mobile Guide

一个基于 Next.js 15 + Tailwind CSS 4 + TypeScript 的鹅鸭杀手游攻略站 MVP。

## 本地启动

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 当前页面

- 首页
- 职业详情页
- 攻略详情页
- 地图详情页

## 下一步建议

1. 加入 `generateStaticParams` 做静态生成
2. 接 MDX 做内容管理
3. 增加 sitemap、robots、Open Graph
4. 接入搜索与标签筛选
